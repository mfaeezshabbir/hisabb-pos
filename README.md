# Hisabb

Offline billing and accounts for produce-market and commission-agent (arhat) businesses.

Built for shop counters: Urdu and English, RTL-aware, keyboard-first. Runs on Windows with a local SQLite database — no internet required for day-to-day work.

## Website

Open the product page: **[Hisabb site](https://mfaeezshabbir.github.io/hisabb-pos/)** (GitHub Pages).

## What it does

- **Sales bills** — traders, buyers, charges, edit and reprint
- **Cash** — batch receipts and payments
- **Accounts & items** — optional Urdu and English names; ledgers that stay in balance
- **Reports** — including trial balance
- **Receipts** — 58 mm, 80 mm, and A4

## Licence

Each shop is unlocked with an **activation key** from the developer. Paste the key in the app and press Activate (needs internet once). After that, Hisabb runs offline on that computer.

If you need a new key or moved to a new PC, contact the developer.
